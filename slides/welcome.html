reclaude

A file system made of web pages

Swipe, tap the edges, or use the arrow keys.

What it is

  • Docs, slide decks and pages, each one a web page
  • Hosted on Cloudflare Pages, so every file has its own link
  • Written by Claude and pushed straight to the repo

How a file gets here

  • Ask Claude for a doc or a deck, from any device
  • Claude writes the HTML and pushes it
  • Cloudflare rebuilds the site in a minute or two
  • Send the link to whoever needs it

Good to know

  • Anyone with a link can open that page, and only that page
  • Keep private or sensitive material out of here
  • Print this page to get a PDF of the deck
