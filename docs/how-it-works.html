How reclaude works

September 25, 2026

reclaude is a small site where every file is a web page. Claude writes the pages and pushes them to a private repository, and Cloudflare Pages publishes each one at its own link.

Addresses

AddressWhat it is
/page-nameOne page, named after its file: docs/trip-plan.html is /trip-plan
/admin/<key>The list of every page, with a copy-link button. The key is set in Cloudflare, not in the repo
anything elseA blank "Not found" page

There is no home page and pages don't link to each other, so someone with one link sees only that page.

Where files live

FolderWhat goes there
docs/Documents to read top to bottom
slides/Slide decks, one <section class="slide"> per slide
pages/Anything else: tools, dashboards, one-off pages

Files starting with _ are templates or drafts and are never published.

Publishing

Every push to main makes Cloudflare rebuild and deploy the site, usually within a minute or two.

This is obscurity, not security. Page names can be guessed and links can be forwarded, so keep anything private or sensitive out of this site.
