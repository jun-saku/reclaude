How reclaude works

September 25, 2026

reclaude is a small site where every file is a web page. Claude writes the pages and pushes them to the repository, and GitHub Pages publishes them so each one has a link you can share.

Where files live

FolderWhat goes there
docs/Documents to read top to bottom
slides/Slide decks, one <section class="slide"> per slide
pages/Anything else: tools, dashboards, one-off pages

The home page lists every .html file in those folders, using each page's title and description. Files starting with _ are templates or drafts and stay off the list.

How publishing works

On every push to main, a GitHub Actions workflow rebuilds the file list and deploys the site. A new page is usually live about a minute after the push.

Sharing

Send the page's link. There's no login, so anyone with the link can open it.

Pages ask search engines not to index them, but that is a request, not protection. Keep anything private or sensitive out of this site.
